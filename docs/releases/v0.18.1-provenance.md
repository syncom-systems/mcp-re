## Infrastructure and harness failures, reported as such

1. **A local mutation-lane run scored probe M84 "did not COMPILE".** Another workspace's
   Bazel server had garbage-collected the shared disk cache, and the remote cache lacked the
   same blobs, so Bazel abandoned its first attempt (`REMOTE_CACHE_EVICTED`), retried within
   the same command, compiled the weakened tree and ran the control, which went red as
   intended (`TESTS_FAILED`). The lane read the abandoned attempt's error text. #1199 makes
   the lane judge a Rust build by Bazel's exit status. The complete hosted run above, which
   uses neither cache, scored all 538 probes.
